# Color

Tokens de color alineados con variables Figma **Calipso 2.0** — colección `Color` (modos light / inverse) y `_ Color · brand` (marcas kubo / maestro). Nombres `ref/*` y `semantic/color/*`.

`src/styles/colors-from-figma.css` (generado desde `src/tokens/figma-color-tokens.ts`) trae `:root` = **kubo light** + un bloque `[data-brand="maestro"]` que redefine solo las 26 familias de marca. En Storybook el toggle **Marca** de la toolbar cambia entre kubo y maestro en vivo (resuelto en `.storybook/preview.ts` mezclando `semantic-theme-aliases.ts` + `brand-aliases.ts`). El swatch board de abajo tiene su propio selector kubo/maestro.

Para regenerar el CSS tras editar el mapa TS:

```bash
npm run tokens:colors
```
