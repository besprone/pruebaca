# Color

Tokens de color alineados con variables Figma **Calipso 2.0** (`ref/color/*`, `semantic/color/*`). CSS generado en `src/styles/colors-from-figma.css` a partir de `src/tokens/figma-color-tokens.ts`.

Para regenerar el CSS tras editar el mapa TS:

```bash
npm run tokens:colors
```
