# Calipso Design System

This repository currently focuses on Foundations and Structure documentation in Storybook, aligned with Figma tokens and naming.

## Current Scope

- Foundations: Color, State, Gradients, Typography, Spacing, Radius, Elevation, Iconography, Motion
- Structure: Grid, Layout
- Token generation scripts and generated CSS assets for those foundations

## Notes

- Component implementation stories were intentionally removed from this stage.
- Storybook is configured in light mode for consistency while documenting foundations.
